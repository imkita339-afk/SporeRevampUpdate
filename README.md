# SporeRevamp — лаунчер

Лаунчер мультиплеер-мода **SporeMP** для Spore: ставит мод, запускает игру и обновляется сам.
Из этого репозитория лаунчеры игроков берут новые версии.

## Установка

1. Нужны Spore и «Космические приключения». Игру из Steam сначала один раз запустите из самого Steam.
2. Поставьте загрузчик модов **Spore ModAPI Launcher Kit**: <https://launcherkit.sporecommunity.com/>.
3. Скачайте [SporeRevamp.exe](https://github.com/imkita339-afk/SporeRevampUpdate/raw/main/SporeRevamp.exe)
   и запустите его. Кнопка **«Играть»** ставит мод и запускает игру.

Windows может показать синее окно «Система Windows защитила ваш компьютер»: у файла нет платной подписи
издателя. Нажмите «Подробнее» → «Выполнить в любом случае».

Дальше скачивать ничего не нужно: при каждом запуске лаунчер проверяет файл `latest.json` из этого репозитория
и, если вышла новая версия, сам скачивает её и перезапускается. У всех игроков должна быть одна версия.

## Как играть вдвоём

Хост запускает игру и входит в мир на этапе «Существо». Гость запускает игру, остаётся на экране галактики и
в списке друзей Steam выбирает у хоста «Присоединиться к игре» — через несколько секунд он окажется в мире хоста.

Совместная игра пока работает только на этапе «Существо».
